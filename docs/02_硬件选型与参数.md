## 2. 关键参数计算

### 2.1 工作距离与视场

相机靶面：OV2710 为 **1/2.7"**，感光面对角 ≈ 6.2 mm，宽 ≈ 5.4 mm（16:9）。

视场估算（薄透镜近似）：
```
视场宽度 W ≈ (传感器宽度 / 焦距 f) × 工作距离 L
```

设计中心值 **L = 300 mm**，要求覆盖目标最大尺寸 200 mm（+余量 250 mm）：

```
f ≈ 5.4 × 300 / 250 ≈ 6.5 mm  → 选 6 mm 或 8 mm 低畸变镜头
```

### 2.2 相机-激光基线角

三角测量基线角 **30°–45°** 为佳：
- 夹角太小 → 深度分辨率低
- 夹角太大 → 遮挡严重

基线距离 `d` 建议 **50–150 mm**（受 50 cm 装置约束）。

### 2.3 激光张角

激光线在距离 L 处长度：
```
线长 ≈ 2 × L × tan(θ/2)
```
L = 300 mm 时，若要覆盖 250 mm：
```
θ ≥ 2 × atan(125 / 300) ≈ 45°
```
→ 选 **扇形张角 45°–60°**。

### 2.4 转台角度分辨率

```
角度分辨率 = 步距角 / (减速比 × 微步 × 每圈整步数/360)
           = 1.8° / (5.18 × 32)
           ≈ 0.0109°
```

整圈微步数 = 200 × 32 × 5.18 ≈ **33 152 步**，即 0.0109°/步。

当前配置 `scan.preset: 720` → 每视角 **46 微步** ≈ **0.4995°**，
累计 359.653°（差 −0.35°，约 0.1%）。

各视角数的实测计划（`plan_scan()`，累计误差在 `{floor, round, ceil}`
三个候选里取最优）：

| 视角数 | 微步/视角 | 实际转角 | 累计 | 误差 |
|---|---|---|---|---|
| 180 | 184 | 1.9981° | 359.653° | −0.35° |
| 360 | 92 | 0.9990° | 359.653° | −0.35° |
| **720** | **46** | **0.4995°** | **359.653°** | **−0.35°** |
| 1080 | 31 | 0.3366° | 363.562° | +3.56° |

**视角数不取整数度**：分度均匀、误差不随视角数放大，比"每视角正好 0.5°"
重要。1080 视角是反例——整圈 33 152 步不能被 1080 整除，只能取 31 步，
累计多出 3.56°。

### 2.5 USB 带宽与像素格式（实测约束）

这部分不是"理论选型"，而是**实测踩过的坑**，直接决定采集帧率。

相机 1280×800 = 1 024 000 像素。USB 2.0 高速理论 480 Mbit/s（60 MB/s），
UVC 等时传输扣除协议包开销与驱动后，实测可用约 **36–40 MB/s**。

| 格式 | 每像素 | 帧大小 | 60 fps 需求 | 可用帧率 |
|---|---|---|---|---|
| YUY2（未压缩 4:2:2） | 16 bit | **2.05 MB** | **122.9 MB/s** | 受带宽限制，实测 **10 fps** |
| MJPG（帧内压缩） | ≈1.5 bit（估） | **≈0.19 MB** | **≈11.5 MB/s** | 实测 **69 fps** |

结论：**1280×800 下必须用 MJPG**，否则每帧多等 ~85 ms，720 视角累计
多出 10 分钟。

> MJPG 的 bit/px 是平均压缩比的量级估计，随画面纹理变化；激光扫描画面
> 大面积暗背景，实际压缩率更高。这一行的用途是判断"带宽是否还是瓶颈"，
> 不是精确预算。

**设置顺序**：部分 UVC 驱动（实测 `CAP_DSHOW` + Sunplus）在改变分辨率时
会重置像素格式。因此必须 **先设分辨率、再设四码，并回读确认**；否则日志
显示 MJPG 而实际跑 YUY2。实现细节与排查见 `10_采集链路与性能.md`。

**黑白相机的像素格式**：`Y800` 是 DirectShow 工业相机格式，通用 UVC
相机通常不支持。配置里 `fourcc_mono` 留空，由通道判定（逐帧比较 R/B/G
中位差）识别"三通道包装的灰度"。详见 10 §3。

### 2.6 配置中与本节对应的键

```yaml
camera:
  width: 1280
  height: 800
  fourcc: MJPG        # 唯一能突破 USB2.0 带宽的方案
  fourcc_mono: ""     # 通用 UVC 不支持 Y800，留空
  fps: 60             # 相机实际能到 69，留 60 给驱动调度余量
  mono: true
  discard_frames: 1   # MJPG 14.5ms/帧，丢 1 帧足够
  exposure: -8
  gain: 100
```

### 2.7 激光线宽

要求目标处线宽 **0.3–0.5 mm**。
```
目标处线宽 ≈ 标称线宽 × (工作距离 / 标称距离)
```
须选**可调焦**模块，将焦点调至 L = 300 mm。

## 3. 供电设计

```
        ┌─────────────────────────────────────┐
        │       3S 锂电池 (11.1V) + BMS          │
        └──────┬───────────────────┬──────────┘
         保险丝 │               降压 │
               ▼                    ▼
        ┌────────────┐      ┌────────────────┐
        │  TB6600    │      │  DC-DC 5V Buck  │
        │ (12V直供)  │      └───┬────────┬───┘
        └─────┬──────┘          │        │
              ▼                 ▼        ▼
        步进电机            单片机      线激光
```

要点：
1. 电机电源与信号电源**分离**，避免干扰；
2. 所有模块**共地**；
3. 电池需 **BMS 保护板**；
4. 电机电源加大电解电容（470–1000 µF）吸收冲击；
5. 3S (12.6V 满) 正好匹配 TB6600 最佳工作电压。

## 5. 电机接线

17HS4401 为两相四线（A+, A-, B+, B-）：

| 电机线 | 接 TB6600 |
|---|---|
| A+ | A+ |
| A- | A- |
| B+ | B+ |
| B- | B- |

> 接线前用万用表测通断分组，确认 A/B 相，避免接错。

## 6. 结构设计要点

- 底板刚性（铝型材/厚板），避免振动与形变；
- 相机支架俯仰可调 + 锁死（复用 `camera-holder`）；
- 激光支架倾角可调 + 锁死（复用 `laser-holder`）；
- 转台承载目标，**不接触目标本体**（目标顺势放置）；
- 整体包络 ≤ 50 × 50 × 50 cm，质量 ≤ 10 kg；
- 光路尽量封闭遮光，保护人眼 + 抑制环境光。
