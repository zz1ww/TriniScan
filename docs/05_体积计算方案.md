# 05 · 体积计算方案

体积计算是本题的**最终输出**，也是评分核心。难点在于：**赛题定义体积为
"实体部分实际体积"，通孔、凹槽、缺口等空缺部分不计入。** 因此必须先把
重建网格**封闭化**，再做体积积分。

---

## 1. 总体流程

```
单视角点云 ──► 配准拼接 ──► 全局点云 ──► 三角网格重建
                                              │
                                              ▼
                                     网格封闭化（★关键）
                                     ├─ 去离群
                                     ├─ 补洞
                                     ├─ 封底/封口
                                     └─ 保证水密(watertight)
                                              │
                                              ▼
                                      体积积分
                                     ├─ 散度定理法
                                     └─ 体素法（校核）
                                              │
                                              ▼
                                        volume (cm³)
```

---

## 2. 三角网格重建

### 2.1 点云预处理
- **去离群点**：`remove_statistical_outlier`（k=20, std=2.0）
- **下采样**：`voxel_down_sample`（体素 0.5 mm）
- **法向量估计**：`estimate_normals`（法向一致朝外）

### 2.2 重建方法对比

| 方法 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| **Poisson 重建** | 平滑、抗噪、自动补洞 | 可能过度平滑细节、需裁剪 | ✅ 首选 |
| Ball-Pivoting | 保边、忠实 | 对噪声敏感 | 备选 |
| Alpha Shape | 快 | 参数敏感 | 快速预览 |
| Marching Cubes | 规整 | 体素化误差 | 校核 |

**建议**：主用 **Poisson 重建**，depth=8–10，再做密度裁剪。

---

## 3. 网格封闭化（★得分关键）

Poisson 重建的输出通常**不水密**（有开口、悬浮面），必须先封闭：

### 3.1 处理步骤
1. **裁剪**：按点云密度去除低置信度面片（Poisson 的 density 阈值）；
2. **去离群面片**：删除面积异常/孤立的面片；
3. **补洞**：`fill_holes` / trimesh `fill_holes`；
4. **封底**：对凹槽、通孔等空腔，需根据几何判断是否属于"缺口"；
5. **保证水密**：检查 `mesh.is_watertight`，若否，用凸包/包装法兜底；
6. **法向一致**：确保所有面片法向朝外。

### 3.2 特殊形貌处理
| 形貌 | 处理 |
|---|---|
| **通孔** | 孔壁为实体，孔为空缺 → 重建后按实际壁面，孔两端开放处封住即为"不计入" |
| **盲孔** | 孔壁实体，孔内为空 → 保留孔形，封住孔口 |
| **凹槽** | 保留槽形，封住槽两端 |
| **台阶/斜面** | 正常重建即可 |
| **局部遮挡** | 多视角补全，或对缺面用对称/拟合补 |

> 核心：**物理实体表面 = 重建面；物理空缺 = 需要"封口"补偿**。
> 体积 = 实体所包围的体积，孔洞要"填掉"再算。

### 3.3 封闭化兜底策略
若重建网格难以水密，可用：
- **凸包（Convex Hull）**：仅适用于凸体，会高估（凹处被填）→ 仅作参考
- **Alpha Shape + 封闭**：更贴近凹体
- **体素化封闭**：把点云体素化后按占据栅格封闭 → 稳健

## 4. 体积积分方法

### 4.1 散度定理法（推荐）
对水密三角网格，体积为所有三角面片贡献之和：
```
V = (1/6) · Σ (v1 · (v2 × v3))
```
其中 (v1,v2,v3) 为每个三角面片顶点（要求法向朝外、坐标统一）。

实现（trimesh）：
```python
import trimesh
mesh = trimesh.Trimesh(vertices, faces)
V = mesh.volume        # 单位与输入一致 (m³)
V_cm3 = V * 1e6
```

要点：
- **必须水密**，否则结果错误；
- **法向必须一致朝外**，否则符号错；
- 对多连通体可分别计算再求和。

### 4.2 体素法（校核）
把封闭网格体素化，统计内部体素数 × 体素体积：
```
V ≈ N_inner × vx³
```
- 用于**交叉验证**散度定理结果；
- 对复杂孔洞较直观，但精度受体素大小限制。

### 4.3 两种方法对比与校核
| 方法 | 精度 | 速度 | 依赖 |
|---|---|---|---|
| 散度定理 | 高 | 快 | 水密网格 |
| 体素法 | 中（受体素限制） | 中 | 占据判断 |

**建议**：以散度定理为主，体素法为辅做合理性校核；差异过大说明网格有问题。

## 5. 误差来源与抑制

| 误差源 | 影响 | 抑制 |
|---|---|---|
| 相机标定误差 | 全局尺度/畸变 | 高质量标定 + 复核 |
| 激光平面误差 | 系统性深度偏差 | 多平面拟合 + 标准件校核 |
| 转轴误差 | 多视角错位 | 实测标定 + 精配准 |
| 中心线提取误差 | 表面噪声 | 亚像素算法 + 平滑 |
| 点云配准误差 | 拼接缝 | ICP 精配准 |
| 重建误差 | 表面偏移 | 合适 depth + 密度裁剪 |
| 封闭化误差 | 体积系统性偏差 | 孔洞判据 + 校核 |

### 精度验证方法
- **标准件**：用已知体积的标准块（立方体、圆柱、球）测误差；
- **重复性**：同一物体多次测量，看标准差；
- **交叉法**：散度定理 vs 体素法比对。
