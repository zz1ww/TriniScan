# 06 · 开发计划与里程碑

## 1. 总目标

在比赛中实现：现场随机抽取 1 件基本目标 + 2 件复杂目标，每件 **≤60 秒**
自动完成非接触三维测量并输出体积，误差尽可能小。

## 2. 阶段划分

### 阶段 0 · 准备（1 周）
- [ ] 确定镜头/激光/滤光片选型并采购
- [ ] 搭建框架仓库（本仓库）
- [ ] 机械结构初步设计（复用 ciclop）
- **产出**：采购清单、目录结构、机械方案草图

### 阶段 1 · 硬件打通（1 周）
- [ ] 搭建机械结构与供电
- [ ] MCU 固件：串口收指令、发 STEP/DIR、归零
- [ ] `camera.py` + `turntable.py` + 循环脚本，实现"转-停-拍"存图
- **产出**：能自动转一圈并存下多视角图像
- **验收**：180 张图无丢帧、角度一致

### 阶段 2 · 标定（1 周）
- [ ] 相机内参标定 → `calib_camera.npz`
- [ ] 激光平面标定 → `calib_laser.npz`
- [ ] 转轴标定 → `calib_axis.npz`
- [ ] 标定验证（重投影误差、标准件）
- **产出**：三套标定文件 + 误差报告
- **验收**：重投影误差 < 0.5 px

### 阶段 3 · 单视角三维点云（1 周）
- [ ] 激光中心线提取（灰度重心 / Steger）
- [ ] 三角测量（像素 → 相机系 3D 点）
- [ ] 可视化单剖面点云
- **产出**：单视角点云
- **验收**：平面/台阶测量与真值一致

### 阶段 4 · 多视角重建（1–2 周）
- [ ] 多视角点云按转轴变换统一
- [ ] ICP 精配准
- [ ] Poisson 网格重建 + 裁剪
- **产出**：完整三角网格
- **验收**：闭合形状完整、无明显错缝

### 阶段 5 · 体积计算（1 周）
- [ ] 网格封闭化（补洞/封底）
- [ ] 散度定理体积积分
- [ ] 体素法校核
- **产出**：体积数值 + 误差分析
- **验收**：标准件误差 < 2%

### 阶段 6 · 自动化与提速（1 周）
- [ ] `pipeline.py` 全流程自动化
- [ ] 计时，压缩到 ≤60 秒
- [ ] 异常处理与日志
- **产出**：一键测量
- **验收**：稳定 ≤60 秒/件

### 阶段 7 · 冲高分（1–2 周）
- [ ] 转台精度优化（编码器/标定补偿）
- [ ] 复杂形貌补盲区（俯仰/双相机）
- [ ] 封闭化算法打磨
- [ ] 误差分析报告
- **产出**：优化后的精度与鲁棒性

### 阶段 8 · 交付（1 周）
- [ ] 成本清单
- [ ] 海报（30 分）
- [ ] 系统说明 / 测量说明
- [ ] 现场演练

| 角色 | 职责 |
|---|---|
| 光学/标定 | 相机/激光/转轴标定，精度把控 |
