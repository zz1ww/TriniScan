# 03 · 软件架构设计

## 1. 设计原则

- **分层解耦**：底层通用能力（几何/IO/日志）→ 中层算法（标定/提取/重建/体积）
  → 顶层编排（pipeline/入口）。上层依赖下层，下层不感知上层。
- **模块化、可替换**：每个算法模块提供统一入口 + 可注册扩展
  （如中心线提取的 `_METHODS` 注册表、标定结果 dataclass）。
- **配置驱动**：所有硬件参数、路径、算法参数集中在 `config/default.yaml`，
  代码不写死；运行期可覆盖。
- **可测试**：核心算法为纯函数或轻状态对象，配套单元测试（47 个用例）。
- **单位统一**：长度米 (m)，体积输出 cm³，角度度 (°)，时间秒 (s)。
- **日志规范**：统一 `get_logger(__name__)`，不用 print。

## 3. 依赖方向

```
        ui / tools / core.main
                 │
        core.pipeline（编排）
                 │
   ┌─────────────┼──────────────┬─────────────┐
 camera       turntable    calibration    reconstruction ──► volume
   │             │             │               │               │
   └─────────────┴─────────────┴───────────────┴───────────────┘
                              │
                        common（几何/IO/日志）
```

`common` 是最底层，不依赖任何业务模块。

## 4. 主控状态机（pipeline）

```
    ┌──────────┐
    │  IDLE    │
    └────┬─────┘
         ▼
   load_calibrations ── 缺失 → 报错
         ▼
    acquire（转-停-拍，逐视角存盘）
         ▼
   reconstruct_views（提取 → 三角测量，逐视角）
         ▼  无有效视角 → 报错
   build_pointcloud（按转轴变换 + ICP + 融合）
         ▼
   measure_volume（Poisson 重建 → 封闭化 → 体积 + 校核）
         ▼
   ScanResult（体积 / 用时 / 各阶段耗时 / 质量指标）
```

每阶段独立方法，记录耗时，超 60s 告警。

## 5. 关键数据结构

| 类型 | 位置 | 说明 |
|---|---|---|
| `CameraConfig` / `TurntableConfig` | camera/turntable | 硬件配置 |
| `CameraCalibResult` | calibration.camera_calib | K, dist, rms, 每视角误差 |
| `LaserCalibResult` | calibration.laser_calib | 平面，残差，视角数 |
| `AxisCalibResult` | calibration.axis_calib | 轴上一点+方向，半径，残差 |
| `ViewCloud` | reconstruction.register | 单视角点云 + 角度 |
| `MeshResult` | reconstruction.mesh | 网格 + 统计 |
| `CloseMeshResult` | volume.close_mesh | 水密网格 + 兜底策略 |
| `VolumeResult` | volume.volume | 体积 + 校核 + 相对差 |
| `ScanResult` | core.pipeline | 一次测量完整结果 |

## 6. 配置项（default.yaml 摘要）

见 `software/config/default.yaml`，分组：`camera / turntable / scan /
calibration / camera_calib / laser / extraction / reconstruction / volume /
output / logging`。

## 7. 统一接口约定

```python
# 中心线提取
from triniscan.extraction import extract_centerline
pixels = extract_centerline(image, config)   # -> (N, 2) 亚像素

# 三角测量
from triniscan.reconstruction import triangulate
points, mask = triangulate(pixels, K, plane, dist, return_mask=True)

# 标定
from triniscan.calibration import (
    calibrate_camera, calibrate_laser_plane, calibrate_axis,
    load_camera_calib, load_laser_calib, load_axis_calib)

# 体积
from triniscan.volume import close_mesh, compute_volume
closed = close_mesh(mesh)
result = compute_volume(closed.mesh, cross_check=True)
print(result.volume_cm3)
```

## 8. 扩展点

| 想扩展 | 怎么做 |
|---|---|
| 新的中心线算法 | `register_method("my_method", func)` 或加入 `_METHODS` |
| 新的重建算法 | 在 `reconstruction/mesh.py` 增加函数并导出 |
| 新的体积判据 | 在 `volume/` 下新增模块 |
| 硬件更换 | 只改 `config/default.yaml` |
| 增加双相机 | 新增 `camera` 实例 + 在 pipeline 融合 |

## 9. 开发顺序

1. 转-停-拍打通
2. 三标定（相机 → 激光平面 → 转轴）
3. 单视角点云（中心线提取 + 三角测量）
4. 多视角重建（配准 + Poisson）
5. 体积计算（封闭化 + 积分）
6. 自动化 ≤60s
7. 精度优化 + 误差分析

## 10. 编码与测试规范

- PEP8 + black（行宽 79）+ isort + ruff；
- 类型注解、dataclass、`from __future__ import annotations`；
- 公共函数写 NumPy 风格 docstring；
- 单位写进 docstring 与变量名；
- 核心算法必须有单元测试；
- 运行测试：`cd software && PYTHONPATH=. pytest tests/ -v`。
