# 03 · 软件架构设计

## 1. 分层架构

```
┌────────────────────────────────────────────────────────────┐
│                        应用层 (ui / core)                    │
│            主控状态机 · 图形界面 · 结果记录                    │
├────────────────────────────────────────────────────────────┤
│                        业务层 (各处理模块)                    │
│  相机采集 │ 转台控制 │ 标定 │ 中心线提取 │ 重建 │ 体积计算      │
├────────────────────────────────────────────────────────────┤
│                        数据层 (数据模型 / IO)                 │
│   图像 · 点云 · 网格 · 标定参数 · 配置文件 · 日志              │
├────────────────────────────────────────────────────────────┤
│                   硬件抽象层 (HAL)                           │
│       相机接口 · 串口接口 （屏蔽具体硬件差异）                 │
└────────────────────────────────────────────────────────────┘
```

## 2. 模块划分

| 包 | 模块 | 职责 | 主要依赖 |
|---|---|---|---|
| `camera` | `capture.py` | 相机打开、锁参数、抓图、存图 | OpenCV |
| `turntable` | `controller.py` | 串口指令、转台归零、旋转、状态回传 | pyserial |
| `calibration` | `camera_calib.py` | 相机内参 + 畸变标定 | OpenCV |
| `calibration` | `laser_calib.py` | 激光平面方程标定 | NumPy/OpenCV |
| `calibration` | `axis_calib.py` | 转台旋转轴标定 | NumPy/SciPy |
| `extraction` | `centerline.py` | 激光中心线亚像素提取 | OpenCV/NumPy |
| `reconstruction` | `triangulate.py` | 像素 → 三维点（三角测量） | NumPy |
| `reconstruction` | `register.py` | 多视角点云配准拼接 | Open3D |
| `reconstruction` | `mesh.py` | 点云 → 三角网格重建 | Open3D |
| `volume` | `close_mesh.py` | 网格补洞 / 封底 / 封闭化 | Open3D/trimesh |
| `volume` | `volume.py` | 封闭网格体积积分 | trimesh |
| `core` | `config.py` | 配置加载 | PyYAML |
| `core` | `pipeline.py` | 单件测量主流程 | 全部 |
| `core` | `main.py` | 程序入口 | pipeline |
| `ui` | `app.py` | 图形界面（可选） | PyQt5 |

```
     ┌─────────────┐

           ▼

           │ 采集完
           ▼
    ┌─────────────┐
    │ PROCESSING  │ 提取→三角测量→配准→重建→封闭→体积
    └──────┬──────┘
           ▼
     ┌──────────┐

      └────────┘

```

```yaml
  index: 0
  width: 1920
  height: 1080
  auto_exposure: false
  exposure: -6

  microstep: 32         # 细分

  camera_file: "software/config/calib_camera.npz"
  laser_file: "software/config/calib_laser.npz"

  wavelength_nm: 650
  power_mw: 1.0
```

## 6. 关键接口约定

### 6.1 转台控制器
```python
class Turntable:
    def connect() -> None
    def home() -> bool                 # 归零
    def rotate_steps(n: int) -> bool   # 走 n 步
    def rotate_deg(angle: float) -> bool
    def enable(on: bool) -> None
    def disconnect() -> None
```

### 6.2 相机
```python
class Camera:
    def open() -> None
    def set_manual(exp, gain) -> None
    def grab() -> np.ndarray           # BGR 图像
    def grab_stable() -> np.ndarray    # 丢弃前若干帧后取帧
    def close() -> None
```

### 6.3 标定
```python
def calibrate_camera(images) -> (K, dist)                # 内参+畸变
def calibrate_laser(pairs) -> np.ndarray                 # 平面 [a,b,c,d]
def calibrate_axis(images, angles) -> (point, direction) # 轴位置+方向
```

### 6.4 提取 / 重建 / 体积
```python
def extract_centerline(img, cfg) -> np.ndarray           # (N,2) 亚像素
def triangulate(centerline, K, plane) -> np.ndarray      # (N,3) 相机系
def register(points_list, angles) -> o3d.PointCloud      # 融合
def reconstruct(pcd, cfg) -> o3d.TriangleMesh            # 网格
def close_mesh(mesh) -> o3d.TriangleMesh                 # 封闭化
def compute_volume(mesh) -> float                        # cm³
```

## 8. 开发顺序

```
S1  camera + turntable      → 打通"转-停-拍"
S2  camera_calib            → 出内参，能去畸变
S3  centerline              → 图上能画激光中心线
S4  laser_calib + triangulate → 单视角出 3D 点云
S5  register + mesh         → 多视角拼成完整网格
S6  close_mesh + volume     → 出体积
S7  pipeline + main         → 全自动 + 计时
S8  优化（封闭/提速/误差）    → 冲高分
```

## 9. 编码规范

- 遵循 PEP 8，使用 `black` 格式化，`isort` 排序导入
- 类型注解（typing）+ 关键函数 docstring
- 所有硬件/路径参数走配置文件，不硬编码
- 每个处理模块可独立运行测试（`if __name__ == "__main__"`）
- 单位统一：长度用 **米 (m)**，体积输出用 **cm³**
