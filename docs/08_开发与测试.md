# 08 · 开发与测试

## 1. 环境准备

```bash
cd software
python -m venv .venv
# Windows
.venv\Scripts\activate
# 安装
pip install -r requirements.txt
# 或安装为包（含开发工具）
pip install -e ".[dev,ui]"
```

Python 版本：**>= 3.10**（当前机器若为 3.8 需升级，
部分语法如 `X | Y` 类型注解需要 3.10）。

## 2. 运行

```bash
# 项目根目录下（保证 software 可导入）
set PYTHONPATH=software          # Windows
export PYTHONPATH=software       # Linux/macOS

python -m triniscan --check              # 检查配置与标定
python -m triniscan                      # 执行测量
python -m triniscan --log-level DEBUG    # 调试日志
```

或用脚本：`scripts\run.bat` / `scripts/run.sh`。

## 3. 测试

```bash
cd software
PYTHONPATH=. python -m pytest tests/ -v
```

当前测试覆盖：

| 文件 | 用例数 | 覆盖内容 |
|---|---|---|
| `test_geometry.py` | 14 | 向量/平面/射线求交/旋转/圆拟合 |
| `test_centerline.py` | 16 | 预处理、灰度重心、Steger 亚像素精度、极值法、方法分发 |
| `test_calibration.py` | 9 | 激光平面/像素射线/转轴/相机内参（合成数据） |
| `test_volume.py` | 8 | 立方体/圆柱/球体积、体素校核、封闭化 |
| **合计** | **47** | 全部通过 |

### 关键验收指标（测试内断言）

- **Steger 亚像素精度**：多种真实中心位置下误差 **< 0.05 px**；
- **体积精度**：立方体/圆柱/球与解析解相对误差 < 1%~5%；
- **几何自洽**：平面拟合残差 ~1e-9、转轴圆拟合残差 < 1e-6 m。

## 6. 代码规范

- `black`（行宽 79）、`isort`、`ruff`；
- 所有公共函数写 docstring，注明单位与返回形状；
- 硬件参数一律走配置，不硬编码；
- 算法模块纯函数优先，状态对象用 dataclass。

```bash
black triniscan tests
isort triniscan tests
ruff check triniscan tests
```

## 7. 调试建议

| 症状 | 排查 |
|---|---|
| 相机打不开 | 换 `camera.backend`、改 `index` |
| 激光太亮/太暗 | 调 `camera.exposure`、`extraction.threshold` |
| 中心线断裂 | 降 `threshold`、增 `smooth_sigma`、用 `steger` |
| 点云错位 | 检查转轴标定与 `angle_step_deg` |
| 网格不水密 | 调 `density_quantile`、加密视角、用体素兜底 |
| 体积偏差大 | 先验标准件，逐项排查标定/提取/重建 |

## 8. 环境注意

- 本项目代码使用 Python 3.10+ 语法；若环境为 3.8，需升级 Python
  或改用 `typing.Optional` 等兼容写法。
- `open3d` 提供较新 Python 版本的 wheel；如安装失败请优先升 Python。
