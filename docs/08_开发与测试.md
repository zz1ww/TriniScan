# 08 · 开发与测试

## 1. 环境准备

```bash
cd software
python -m venv .venv
# Windows
.venv\Scripts\activate
# 安装
pip install -r requirements.txt
# 或安装为包（含开发工具）
pip install -e ".[dev,ui]"
```

Python 版本：**>= 3.10**（当前机器若为 3.8 需升级，
部分语法如 `X | Y` 类型注解需要 3.10）。

## 2. 运行

```bash
# 项目根目录下（保证 software 可导入）
set PYTHONPATH=software          # Windows
export PYTHONPATH=software       # Linux/macOS

python -m triniscan --check              # 检查配置与标定
python -m triniscan                      # 执行测量
python -m triniscan --log-level DEBUG    # 调试日志
```

或用脚本：`scripts\run.bat` / `scripts/run.sh`。

## 3. 测试

```bash
cd software
PYTHONPATH=. python -m pytest tests/ -q            # 全量
PYTHONPATH=. python -m pytest tests/test_scan_plan.py -v
```

当前规模：**39 个测试文件、424 个用例通过、1 个跳过**，约 2 分钟
（Windows + Python 3.8 实测）。

### 3.2 关键验收指标（测试内断言）

- **Steger 亚像素精度**：多种真实中心位置下误差 **< 0.05 px**；
- **体积精度**：立方体/圆柱/球与解析解相对误差 < 1%~5%；
- **几何自洽**：平面拟合残差 ~1e-9、转轴圆拟合残差 < 1e-6 m；
- **角度计划**：累计角度误差 < 1 步，分度完全均匀；
- **参数默认值**：`AlgorithmSpec` 声明的默认值与 yaml 一致（防止漂移）。

## 6. 图形界面

```bash
python -m triniscan.ui                 # 工作台界面（默认）
python -m triniscan.ui --ui classic    # 旧两页界面（回退）
scripts\gui.bat
```

三个工作台：**测量 / 标定 / 硬件**，顶部下拉切换。

| 区域 | 说明 |
|---|---|
| 左侧面板 | 可折叠参数分组，由 `FieldSpec` 自动生成控件，改动即时生效 |
| 右侧视图 | 实时画面（含中心线叠加）/ 重建结果页，互斥切换 |
| 底部工具条 | ▶ 开始测量 / ▶ 预览 / 中心线 / 显示画面·结果 / 图像上限 / ⚙ 从图像重建 |

实现要点：

- 耗时操作（预览、采集、重建、串口）全部经 `ui/worker.py` 的
  `Worker` 放到**后台线程**，结果经 `queue.Queue` 回传，UI 线程用
  `after()` 轮询刷新。**后台线程只写队列，绝不碰控件**；
- 界面与业务解耦：GUI 只调用 `ScanPipeline` 的公开方法，与命令行
  共用同一套配置与代码路径；
- 模块化：`workbench.py`（基类）、`workbench_*.py`（三个场景）、
  `params.py`/`field_spec.py`（参数表）、`rebuild_job.py`（后台重建）、
  `video.py`（实时画面）。

架构与操作细节见 `11_界面架构与操作.md`。

## 7. 代码规范

- `black`（行宽 79）、`isort`、`ruff`；
- 所有公共函数写 docstring，注明单位与返回形状；
- 硬件参数一律走配置，不硬编码；
- 算法模块纯函数优先，状态对象用 dataclass。

```bash
black triniscan tests
isort triniscan tests
ruff check triniscan tests
```

## 8. 调试建议

| 症状 | 排查 |
|---|---|
| 相机打不开 | 换 `camera.backend`、改 `index` |
| 激光太亮/太暗 | 调 `camera.exposure`、`extraction.threshold` |
| 中心线断裂 | 降 `threshold`、增 `smooth_sigma`、用 `steger` |
| 点云错位 | 检查转轴标定与 `angle_step_deg` |
| 网格不水密 | 调 `density_quantile`、加密视角、用体素兜底 |
| 体积偏差大 | 先验标准件，逐项排查标定/提取/重建 |

## 9. 环境注意

- 本项目代码使用 Python 3.10+ 语法；若环境为 3.8，需升级 Python
  或改用 `typing.Optional` 等兼容写法。
- `open3d` 提供较新 Python 版本的 wheel；如安装失败请优先升 Python。
