# 04 · 标定方案

标定是精度的基础。本系统需要**三类标定**，按重要性排序：

1. **相机标定**（内参 + 畸变）
2. **激光平面标定**（★最关键）
3. **转台旋转轴标定**

---

## 1. 相机标定（内参 + 畸变）

### 目的
求相机内参矩阵 `K` 和畸变系数 `dist`，把像素坐标映射为归一化射线。

```
        ┌ fx  0  cx ┐
K  =    │ 0  fy  cy │        dist = [k1, k2, p1, p2, k3]
        └ 0   0   1 ┘
```

### 方法
张正友标定法（棋盘格），OpenCV `calibrateCamera`。

### 步骤
1. 打印棋盘格标定板（如 9×6，方格 20 mm），贴于刚性平面；
2. 在相机前拍摄 **15–25 张**不同姿态的棋盘格；
3. 检测角点 `findChessboardCorners` + `cornerSubPix`；
4. `calibrateCamera` 求 `K, dist`；
5. 计算重投影误差（应 < 0.5 pixel）；
6. 保存 `calib_camera.npz`。

### 注意
- 棋盘格要覆盖整个视场（含边角），否则畸变标不准；
- 标定板保持平整，姿态多样（倾斜/旋转/远近）；
- 标定时光圈/焦距/工作距离应与实际测量一致。

---

## 2. 激光平面标定（★核心）

### 目的
求激光平面在**相机坐标系**下的平面方程：
```
a·X + b·Y + c·Z + d = 0      →   平面法向量 n = (a, b, c)
```

这是把"激光像素 + 相机射线"还原为三维点的关键。

### 方法（推荐：棋盘格 + 已知平面法）

**原理**：让激光线投射到**已知位置的标定平面**上，由相机看到激光与棋盘格的
交点。棋盘格平面在相机系下的位姿已知（通过相机外参求解），因此激光线上各点
的三维坐标已知（在棋盘格平面上），多条线组合即可拟合激光平面。

**步骤**：
1. 在多个不同距离/姿态下，把棋盘格放在激光光路中；
2. 同时拍下**棋盘格 + 激光线**图像；
3. 求每张图棋盘格平面在相机系下的方程（外参 `solvePnP`）；
4. 提取激光中心线，反算其在棋盘格平面上的三维点；
5. 收集 ≥ 3 个不同平面位姿的激光点集；
6. 最小二乘拟合激光平面 `[a, b, c, d]`；
7. 保存 `calib_laser.npz`。

### 备选方法（位移法）
把一块白板沿已知方向（如 Z）移动多个已知位置，每次记录激光线，
由"像素 + 已知深度"反算三维点，再拟合平面。

### 验证
用已知尺寸标准块测体积，反算误差；若系统性偏差，检查激光平面。

## 3. 转台旋转轴标定

### 目的
确定转台旋转轴在相机坐标系中的**位置 `P` 与方向 `V`**，用于多视角点云配准。

### 方法
1. 转台上放置一个标记物（或标准圆柱/标定球）；
2. 转台转多个角度（如每 30°），各拍一张；
3. 提取标记物特征点（圆心/球心），得到一组绕轴旋转的点；
4. 由这组点拟合圆 → 圆心与法线；
5. 圆心 + 法线 → 旋转轴 `(P, V)`。

### 简化法
若能保证机械安装精度，也可用**几何假设**（旋转轴过转台中心、平行于相机某轴），
但精度有限，建议实测标定。

### 保存
`calib_axis.npz`：`point = [x, y, z]`, `direction = [vx, vy, vz]`。

---

## 4. 手眼关系 / 坐标变换

多视角配准需要把每个视角的相机系点云变换到统一的世界系：

```
P_world = T_axis(θ) · P_cam
```

其中 `T_axis(θ)` 是绕旋转轴转 θ 的变换（Rodrigues 公式）。

若旋转轴为 `(P, V)`，转角 θ 的变换矩阵：
```
T(θ) = Translate(P) · Rot(V, θ) · Translate(-P)
```

---

## 5. 标定流程总览

```
[棋盘格] ──► 相机标定 ──► K, dist ──┐
                                     │
[棋盘格+激光] ──► 激光平面标定 ──► 平面方程 ──┐
                                              ├─► 三角测量
[标记物旋转] ──► 转轴标定 ──► (P, V) ────────┘
                                              │
                                              ▼
                                        三维点云 / 配准
```

## 6. 标定文件格式（.npz）

| 文件 | 内容 |
|---|---|
| `calib_camera.npz` | `K`, `dist`, `image_size`, `rms_error` |
| `calib_laser.npz` | `plane=[a,b,c,d]`, `residual` |
| `calib_axis.npz` | `point`, `direction` |

## 8. 标定注意事项（踩坑清单）

1. **锁曝光**：标定与测量必须用相同相机参数；
2. **棋盘格平整**：翘曲会导致外参错误；
3. **激光平面标定点多平面**：单一平面无法约束平面法向，必须多姿态；
4. **转轴标定精度**：轴误差会随半径放大；
5. **标定后验证**：用标准件复核，误差超标要重标；
6. **参数存档**：每次标定记录时间/条件，避免混用。
