# 01 · 系统总体设计

## 1. 设计目标

依据《第十五届全国大学生光电设计竞赛赛题二》，设计一套低成本、高精度、
非接触式的复杂目标物体三维体积测量系统。

| 指标 | 目标值 | 依据 |
|---|---|---|
| 单件测量时间 | ≤ 60 s | 赛题规则第 7 条 |
| 系统尺寸 | ≤ 50 × 50 × 50 cm | 赛题规则第 2 条 |
| 系统质量 | ≤ 10 kg | 赛题规则第 2 条 |
| 目标尺寸 | 5–20 cm | 赛题规则第 4 条 |
| 目标体积 | 50–2000 cm³ | 赛题规则第 4 条 |
| 测量方式 | 非接触 | 赛题规则第 2 条 |
| 体积口径 | 实体部分体积（孔洞不计） | 赛题规则第 5 条 |

## 2. 技术路线选型

| 路线 | 精度 | 成本 | 复杂度 | 结论 |
|---|---|---|---|---|
| **线激光三角法（光切法）** | 高 | 低 | 中 | ✅ **采用** |
| 结构光（正弦条纹） | 很高 | 中 | 高 | 备选升级 |
| 双目/多目立体视觉 | 中 | 低 | 中 | 用作补盲区辅助 |
| 激光轮廓仪/商用扫描仪 | — | — | — | ❌ 规则禁止 |

**决策**：主方案采用**线激光三角法 + 转台多视角融合**。理由：
1. 完全符合赛题允许器件清单（低功率线激光器 + 普通相机 + 机械转台）；
2. 成本低、结构简单、光路稳定；
3. 单剖面精度可做到亚毫米，满足 5–20 cm 目标测量。

## 3. 系统组成

```
┌─────────────────────────────────────────────────────────┐
│                      上位机 (PC / Windows)                │
│    采集调度 · 标定 · 中心线提取 · 重建 · 体积计算 · 显示     │
└───────┬─────────────────────────────────────┬───────────┘
        │ USB                                  │ 串口/USB
┌───────▼────────┐                    ┌────────▼─────────┐
│   成像子系统    │                    │   运动控制子系统   │
│ 相机 + 镜头     │                    │ MCU + 驱动器 + 电机│
│ (+滤光片/偏振片) │                    │  + 减速 + 转台     │
└───────┬────────┘                    └────────┬─────────┘
        │                                      │
        │            光路                       │
        └──────────► 目标物 ◄───────────────────┘
                       │
              ┌────────▼────────┐
              │   光源子系统     │
              │ 线激光 + 驱动电源 │
              └─────────────────┘
```

### 3.1 成像子系统
- 相机：ELP USBFHD01M（OV2710, 1080P）→ 后续可升级黑白全局快门工业相机
- 镜头：低畸变定焦镜头（6–8 mm，匹配 1/2.7" 靶面）
- 辅件：窄带滤光片（抑制环境光）、偏振片（抑制镜面反光）

### 3.2 光源子系统
- 线激光器：≤1–5 mW，650 nm（或 405 nm），可调焦，均匀一字线（鲍威尔棱镜）
- 驱动：恒流源 / 可调稳压，独立供电
- 安全：标明安全等级 + 遮光罩 + 封闭光路

### 3.3 运动控制子系统
- 电机：NEMA17 17HS4401（1.8° 步距角，1.5 A）
- 驱动：TB6600（最高 1/32 细分）
- 减速：同步带/齿轮 3:1 ~ 5:1
- 转台：承载目标（ciclop disc-holder 或 3D 打印圆盘）
- 控制：MCU（STM32/Arduino/ESP32）产生 STEP/DIR/EN，接收上位机指令
- 附加：限位开关（归零）、旋转编码器（可选，闭环反馈）

### 3.4 计算子系统
- 上位机：笔记本（规则不计入尺寸与成本）
- 软件：Python + OpenCV + Open3D + trimesh + pyserial

## 4. 坐标系定义

| 坐标系 | 说明 |
|---|---|
| 相机坐标系 `C` | 原点在光心，Z 轴沿光轴 |
| 图像坐标系 `I` | 像素坐标 (u, v) |
| 激光平面坐标系 `L` | 激光平面在相机系下的平面方程 |
| 世界/转台坐标系 `W` | 转台旋转轴为 Z 轴，用于多视角统一 |

三角测量：由相机射线（通过内参）与激光平面求交，得到相机系三维点，
再按转台角度变换到世界系。

## 5. 关键设计决策

| 决策点 | 选择 | 理由 |
|---|---|---|
| 物体自转 vs 相机公转 | **物体自转** | 结构简单、光路稳定、成本低 |
| 快门 | 优先全局快门；现用相机则"转-停-拍" | 卷帘快门连续拍有畸变 |
| 同步方式 | 先软件同步，后 MCU 硬触发 | 先跑通再提速 |
| 供电 | 3S 锂电（可用适配器） | 现场灵活；适配器不计成本 |
| 激光波长 | 650 nm（备选 405 nm） | 成熟/便宜；405 更细 |
| 计算平台 | Windows + Python | 生态完善、开发快 |

## 6. 约束与红线（必须遵守）

1. **禁止**使用商用三维扫描仪、结构光扫描仪、激光轮廓仪、工业视觉测量仪、
   成套体积测量仪，或可直接输出三维测量结果的成套设备；
2. **禁止**深度相机/TOF 作为体积测量的主数据来源（仅可辅助定位/演示）；
3. 测量过程**不得接触、夹持、按压、浸没、称重或破坏**待测物；
4. **不得**手动调整目标姿态、人工描边、手工读取尺寸、人工修正体积；
5. 不得在目标表面粘贴标记、喷涂或添加辅助结构；
6. 所有主动发光器件需满足安全要求，激光须标明安全等级并遮光防护；
7. 现场布置不得影响其他队伍比赛。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 卷帘快门畸变 | 点云误差 | 转-停-拍 + 稳定延时；后续换全局快门 |
| 转台丢步/角度误差 | 多视角错位 | 减速 + 微步 + 编码器/标定补偿 |
| 镜面/高光反光 | 中心线失效 | 漫反射材料 + 偏振片 + 多帧平均 |
| 遮挡盲区（凹槽/通孔） | 重建缺面 | 增加俯仰视角 / 双相机 |
| 环境光干扰 | 信噪比下降 | 窄带滤光片 + 遮光箱 + 锁曝光 |
| 网格未封闭 | 体积错误 | 补洞 + 封底算法 |
| 60s 时间压力 | 超时判负 | 减少视角数 + GPU/优化算法 |
