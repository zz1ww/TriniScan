# TriniScan

> **激光三角测量三维体积测量系统** (Laser Triangulation Volumetric Scanner)
>
> 第十五届全国大学生光电设计竞赛 · 赛题二
> 《基于光电技术的复杂目标物体体积高精度测量》

---

## 项目简介

TriniScan 是一套**低成本、高精度、非接触式**三维体积测量系统。采用
**线激光光切法（Laser Line Triangulation）**，通过"物体自转 + 激光/相机固定"
的方式，对 5–20 cm、50–2000 cm³ 的复杂目标物体（含曲面、凹槽、台阶、通孔、
盲孔、斜面等）进行多视角三维重建，并自动计算物体实体体积。

**设计目标**

| 指标 | 目标值 |
|---|---|
| 单件测量时间 | ≤ 60 s |
| 系统尺寸 | ≤ 50 × 50 × 50 cm |
| 系统质量 | ≤ 10 kg |
| 体积测量误差 | ≤ 2 %（争取 ≤ 1 %） |
| 工作距离 | ~300 mm |
| 激光安全等级 | Class 2（低功率） |

## 系统原理

```
        ┌──────────┐            ┌──────────┐
        │  相机     │            │  线激光   │
        │ (CMOS)   │            │ (≤1-5mW) │
        └────┬─────┘            └────┬─────┘
             │  基线 d (50-150mm)     │
             │       \   30°-45°     │
             └────────┐  │  ┌────────┘
                      ▼  ▼  ▼
                   ┌───────────┐
                   │   目标物   │  ← 激光线扫描表面
                   │  (转台上)  │
                   └─────┬─────┘
                   ┌─────▼─────┐
                   │  旋转转台  │ ← NEMA17 + 减速
                   └───────────┘
```

1. 线激光投射到目标表面，形成一条变形激光线（反映表面高度）。
2. 相机从另一角度拍摄该激光线。
3. 通过**相机内参 + 激光平面方程**，用三角测量将像素坐标还原为三维点。
4. 转台每转一个小角度采集一次，得到多视角点云。
5. 点云配准拼接 → 三角网格重建 → 网格封闭化 → 体积积分。

## 配置管理（ConfigStore）

界面与业务模块**共用同一份配置**，改参数流程如下：

```
界面改参数 ─► ConfigStore.update() ─► 内存立即生效（测量/标定随即读到新值）
                                  └─► 标记"未保存"
点「💾 保存配置」 ─► ConfigStore.save() ─► 原子写回 default.yaml
```

- 主窗口、参数面板、标定面板持有**同一个** `ConfigStore` 实例；
- `MainWindow.cfg` 始终返回 `store.cfg`，因此测量（`ScanPipeline`）与
  标定（`CaptureSession`）读取的都是最新值；
- 关闭窗口时若有未保存改动会提示保存。

## 软件链路

```
串口控制转台 ──► 相机采集 ──► 激光中心线提取 ──► 三角测量(像素→3D)
     ▲                                                    │
     │                                                    ▼
  转-停-拍循环                                    多视角点云配准拼接
                                                          │
                                                          ▼
                    体积积分 ◄── 网格封闭化 ◄── 三角网格重建
                        │
                        ▼
                   结果显示 / 记录
```

**软件栈**：Python 3.10+ / OpenCV 4.8+（兼容 5.x）/ NumPy / SciPy /
Open3D / trimesh / pyserial

**采集层关键约束**（详见 [`docs/10_采集链路与性能.md`](docs/10_采集链路与性能.md)）：

| 项 | 值 | 原因 |
|---|---|---|
| 像素格式 | `MJPG` | 1280×800 未压缩 YUY2 需 123 MB/s，超 USB 2.0 可用带宽（36–40 MB/s），只有 10 fps；MJPG 实测 69 fps |
| 设置顺序 | 分辨率 → 帧率 → 四码 → 回读确认 | 部分 UVC 驱动改分辨率时会重置像素格式 |
| 写盘 | 后台线程 + 有界队列（30） | 单张 PNG 约 55 ms，放在采集循环里等于白等 |
| 每视角耗时 | 转台 41 ms + 停稳 30 ms + 取帧 15 ms ≈ **76 ms** | 720 视角约 **55 s** 采完 |

## 快速开始

### 1. 环境依赖

```bash
pip install -r software/requirements.txt
```

> **务必固定用一个 Python 解释器。** 机器上常装多个 Python，
> 各自可能带不同版本的 OpenCV（4.x / 5.x）。用 A 装依赖、用 B 跑
> 程序，会出现"我这边好好的、你那边报错"的假象。
>
> ```bash
> py -3.12 -m pip install -r software/requirements.txt
> py -3.12 -m triniscan.ui
> ```
>
> Python 3.8 已停止支持（EOL），建议用 **3.10 及以上**。
> OpenCV **4.8+ 与 5.x 均已适配**；如遇疑难标定报错，可临时
> 锁到 4.x：`pip install "opencv-python>=4.8,<5.0"`。

### 2. 固件烧录

转台控制器提供两套等价固件（串口协议一致，任选其一）：

| 固件 | 位置 | 工具链 |
|---|---|---|
| CubeIDE（HAL，实测通过） | `firmware/mcu_stm32_cubeide/` | STM32CubeIDE |
| 标准库（Keil5） | `firmware/mcu_stm32_spl/` | Keil MDK5 |

详见各自目录下的 `README.md`。

### 3. 运行

```bash
# 项目根目录下
set PYTHONPATH=software            # Windows
python -m triniscan --check        # 检查配置与标定
python -m triniscan                # 执行测量
```

### 4. 图形界面

基于标准库 **Tkinter**（随 Python 附带）：

```bash
python -m triniscan.ui                 # 工作台界面（默认）
python -m triniscan.ui --ui classic    # 旧两页界面（回退）
# 或 scripts\gui.bat
```

界面按**工作台**组织，顶部下拉切换（详见
[`docs/11_界面架构与操作.md`](docs/11_界面架构与操作.md)）：

```
┌──────────────────────────────────────────────────────────┐
│ 工作台：[测量 ▼]                          已加载标定 / 提示 │
├────────────────────┬─────────────────────────────────────┤
│ 左侧可折叠面板      │ 右侧主视图（实时画面 / 重建结果）      │
│  相机 / 扫描计划    │                                     │
│  提取 / 过滤链      │                                     │
│  配准 / 网格        │                                     │
│  封闭 / 体积        │                                     │
├────────────────────┴─────────────────────────────────────┤
│ [▶ 开始测量] │ [▶ 预览] ☑中心线 │ [显示画面][显示结果] │   │
│ 图像上限 [__] │ [⚙ 从图像重建]                       12 fps │
└──────────────────────────────────────────────────────────┘
```

| 工作台 | 用途 |
|---|---|
| **测量** | 调参 + 实时预览 + 完整测量 / 从已有图像重建 |
| **标定** | 相机内参、激光平面、转轴；顶部状态卡提示标定是否过期 |
| **硬件** | 转台连接、手动转动、分度扫描、急停 |

两个测量入口的区别：

- **▶ 开始测量**：完整流程，归零 → 逐视角转动/抓图 → 重建 → 体积
  （需要相机与转台）；
- **⚙ 从图像重建**：跳过采集，直接用 `data/raw` 里的图像跑
  “提取 → 三角 → 配准 → 网格 → 体积”（调参、复现、无硬件时用）。
  配合「图像上限」填 20~50，一轮迭代从几分钟压到几秒。

**参数编辑与保存**：左侧面板直接修改配置：

- 改动**立即在内存生效**——随后「开始测量」「标定」即使用新值；
- 菜单 文件 → 保存（`Ctrl+S`）写回 `software/config/default.yaml`；
- 有未保存改动时状态栏提示；关闭窗口会询问是否保存。

耗时操作（预览、采集、重建、串口）全部在后台线程执行，界面不卡死。

### 5. 测试

```bash
cd software
PYTHONPATH=. python -m pytest tests/ -q      # 39 个文件 / 424 用例，约 2 分钟
PYTHONPATH=. python -m pytest tests/test_scan_plan.py -v
```

无 pytest 环境时可用 `python tools/_mini_pytest.py`（不支持类内测试）。
