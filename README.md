# TriniScan

> **激光三角测量三维体积测量系统** (Laser Triangulation Volumetric Scanner)
>
> 第十五届全国大学生光电设计竞赛 · 赛题二
> 《基于光电技术的复杂目标物体体积高精度测量》

---

## 项目简介

TriniScan 是一套**低成本、高精度、非接触式**三维体积测量系统。采用
**线激光光切法（Laser Line Triangulation）**，通过"物体自转 + 激光/相机固定"
的方式，对 5–20 cm、50–2000 cm³ 的复杂目标物体（含曲面、凹槽、台阶、通孔、
盲孔、斜面等）进行多视角三维重建，并自动计算物体实体体积。

**设计目标**

| 指标 | 目标值 |
|---|---|
| 单件测量时间 | ≤ 60 s |
| 系统尺寸 | ≤ 50 × 50 × 50 cm |
| 系统质量 | ≤ 10 kg |
| 体积测量误差 | ≤ 2 %（争取 ≤ 1 %） |
| 工作距离 | ~300 mm |
| 激光安全等级 | Class 2（低功率） |

## 系统原理

```
        ┌──────────┐            ┌──────────┐
        │  相机     │            │  线激光   │
        │ (CMOS)   │            │ (≤1-5mW) │
        └────┬─────┘            └────┬─────┘
             │  基线 d (50-150mm)     │
             │       \   30°-45°     │
             └────────┐  │  ┌────────┘
                      ▼  ▼  ▼
                   ┌───────────┐
                   │   目标物   │  ← 激光线扫描表面
                   │  (转台上)  │
                   └─────┬─────┘
                   ┌─────▼─────┐
                   │  旋转转台  │ ← NEMA17 + 减速
                   └───────────┘
```

1. 线激光投射到目标表面，形成一条变形激光线（反映表面高度）。
2. 相机从另一角度拍摄该激光线。
3. 通过**相机内参 + 激光平面方程**，用三角测量将像素坐标还原为三维点。
4. 转台每转一个小角度采集一次，得到多视角点云。
5. 点云配准拼接 → 三角网格重建 → 网格封闭化 → 体积积分。

## 硬件链路

```
                    上位机 PC (Windows)
              ┌──────────┴──────────┐
             USB                  串口/USB
              │                     │
        ┌─────▼─────┐        ┌──────▼──────┐
        │  相机      │        │  单片机 MCU  │
        │ (UVC)     │        └──┬──┬──┬────┘
        └─────┬─────┘     STEP │  │  │ EN
              │             DIR │  │  │
              │        ┌────────▼──▼──▼────┐
              │        │   TB6600 驱动器    │
              │        └────────┬──────────┘
              │             A+/A-/B+/B-
              │        ┌────────▼──────────┐
              │        │ NEMA17 + 减速 + 转台│
              │        └───────────────────┘
              │
         [线激光] ── 独立电源 ── 光路 ── 目标物
```

**供电**：3S/4S 锂电池（带 BMS）→ ① 直供 TB6600 ② DC-DC 降压 5V 供单片机/激光。
电机电源与信号电源分离并共地。

## 快速开始

### 1. 环境依赖

```bash
pip install -r software/requirements.txt
```

### 2. 固件烧录

见 `firmware/mcu/README.md`（Arduino/STM32 转台控制器）。

### 3. 运行

```bash
# 项目根目录下
set PYTHONPATH=software            # Windows
python -m triniscan --check        # 检查配置与标定
python -m triniscan                # 执行测量
```

### 4. 测试

```bash
cd software
PYTHONPATH=. python -m pytest tests/ -v
```
